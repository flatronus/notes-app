# Нотатки (PWA)

Прості нотатки, що працюють без інтернету. Дані зберігаються **локально у файлі `.json`** на вашому пристрої. Хмарної синхронізації немає.

**Поточна версія: 2.1.2**

## Файли
- `index.html` — додаток
- `sw.js` — service worker (кеш для роботи офлайн)
- `manifest.json`, `icon-192.png`, `icon-512.png` — встановлення як PWA

## Як зберігаються дані
- Файл обирається **один раз** (стартовий екран: «Створити новий файл» або «Відкрити існуючий файл»). Додаток запам'ятовує його й надалі відкривається одразу, без вибору файла.
- Кожна зміна **автоматично** записується у файл приблизно через 0,4 с. Паралельно додаток тримає локальну копію в IndexedDB браузера, тому відкривається миттєво й працює навіть тоді, коли доступ до файла ще не надано.
- Якщо доступу до файла немає, поруч з назвою файла стоїть значок ↻. Зміни зберігаються в локальній копії й потрапляють у файл, щойно доступ підключено (перший клік у додатку або клік по назві файла).
- Якщо файл змінили поза додатком, зміни підхоплюються, коли ви повертаєтесь у вікно.
- Кнопка «Файл» у верхній панелі дозволяє вибрати інший файл.
- Індикатор біля назви файла: ⟳ збереження, ✓ збережено, ↻ файл не підключено, ⚠ помилка.

### Дозвіл на запис без повторних запитів
Браузер не дозволяє сайту самому зберегти дозвіл «назавжди», це налаштування користувача:
- **Встановлена PWA** (Chrome/Edge: «Встановити додаток»): дозвіл після одного підтвердження зберігається автоматично.
- **У звичайній вкладці Chrome 122+**: у запиті на доступ оберіть «Дозволяти під час кожного відвідування» (Allow on every visit).

Формат файла: `{ "app": "notes", "version": "...", "notes": [...], "deleted": [...] }`. Шлях до файла додаток не бачить: браузер надає лише посилання на файл, яке додаток і запам'ятовує.

## Підтримка браузерів
- Chrome, Edge (ПК і Android): повна підтримка запису у файл (File System Access API).
- Firefox, Safari, iOS: цього API немає. Додаток зберігає дані в IndexedDB браузера, а кнопка «Експорт» завантажує копію у `.json`.

## Історія версій

### 2.1.2
- Service worker: стратегія «спочатку кеш, оновлення у фоні» замість «спочатку мережа». Додаток більше не чекає мережу під час запуску, тому системна заставка Android триває коротше.
- Нова версія файлів застосовується при наступному запуску після її завантаження.
- Кеш service worker: `notes-v15`.

### 2.1.1
- Прибрано екран-заставку завантаження: робочий простір з'являється одразу, нотатки підвантажуються в нього без проміжного екрана.
- Кеш service worker: `notes-v14`.

### 2.1.0
- Додаток запам'ятовує вибраний файл і відкривається одразу з локальної копії, без стартового екрана та запиту дозволу.
- Файл синхронізується у фоні: якщо доступ є, зміни пишуться відразу, якщо немає, то після першого кліку.
- Зміни, зроблені без доступу до файла, не втрачаються й записуються пізніше.
- Кеш service worker: `notes-v13`.

### 2.0.0
- Прибрано Firebase (Firestore, вхід через Google) та синхронізацію.
- Збереження в локальний файл `.json` з автоматичним записом.
- Новий стартовий екран: створити / відкрити / продовжити файл.
- Автоматичне підхоплення зовнішніх змін файла.
- Запасне сховище IndexedDB та експорт для браузерів без File System Access API.
- Кеш service worker: `notes-v12`.

### 1.x
- Версія з синхронізацією через Firebase Firestore та входом через Google.
