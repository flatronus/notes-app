# Нотатки (PWA)

Прості нотатки, що працюють без інтернету. Дані зберігаються **локально у файлі `.json`** на вашому пристрої. Хмарної синхронізації немає.

**Поточна версія: 2.0.0**

## Файли
- `index.html` — додаток
- `sw.js` — service worker (кеш для роботи офлайн)
- `manifest.json`, `icon-192.png`, `icon-512.png` — встановлення як PWA

## Як зберігаються дані
- Під час першого запуску оберіть «Створити новий файл» або «Відкрити існуючий файл».
- Після цього кожна зміна (створення, редагування, видалення, відновлення) **автоматично** записується у файл приблизно через 0,4 с.
- Файл запам'ятовується. Після перезапуску додаток відкриває його сам. Якщо браузер просить підтвердити доступ, натисніть «Продовжити».
- Якщо файл змінено поза додатком, зміни підхоплюються, коли ви повертаєтесь у вікно.
- Кнопка «Файл» у верхній панелі дозволяє вибрати інший файл.
- Індикатор біля назви файла: ⟳ збереження, ✓ збережено, ⚠ помилка.

Формат файла: `{ "app": "notes", "version": "...", "notes": [...], "deleted": [...] }`

## Підтримка браузерів
- Chrome, Edge (ПК і Android): повна підтримка запису у файл (File System Access API).
- Firefox, Safari, iOS: цього API немає. Додаток зберігає дані в IndexedDB браузера, а кнопка «Експорт» завантажує копію у `.json`.

## Історія версій

### 2.0.0
- Прибрано Firebase (Firestore, вхід через Google) та синхронізацію.
- Збереження в локальний файл `.json` з автоматичним записом.
- Новий стартовий екран: створити / відкрити / продовжити файл.
- Автоматичне підхоплення зовнішніх змін файла.
- Запасне сховище IndexedDB та експорт для браузерів без File System Access API.
- Кеш service worker: `notes-v12`.

### 1.x
- Версія з синхронізацією через Firebase Firestore та входом через Google.
